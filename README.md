# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

顶栏可进「调拨台」专页，分三段：台名册、发起调拨、调拨履历。审评台先登记入册（台名唯一），批次才能在已入册台之间调拨；调拨单含源台、目标台、批次、调拨人、时刻，成功后写入不可删改的履历（数据库触发器拦 UPDATE/DELETE）。未入册的台名出现在调拨单里会被拒（400），履历不增。首页可按审评台过滤：只显示当前在该台的批次，每批取最新一行，过滤在服务端 SQL 完成，不在浏览器本地藏行。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 顶栏进「调拨台」：登记甲台、乙台（重复台名 409）；observer 能看名册与履历，但登台、建调拨单都是 403。
5. 提交一批「春茶甲」审评后，把它从甲台调到乙台：首页按甲台过滤看不到该批，按乙台过滤看得到（均为服务端过滤），履历留一条。
6. 调拨单写未入册的丙台（源或目标）被拒（400），履历不增。
